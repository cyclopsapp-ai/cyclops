# Cyclops for Windows

Live answers for interviews and calls. Cyclops listens to your call, writes down both sides, and suggests answers built from your own resume.

- Website, pricing and FAQ: https://getcyclops.pages.dev
- Download the latest version: [Cyclops-Setup.exe](https://github.com/cyclopsapp-ai/cyclops/releases/latest/download/Cyclops-Setup.exe) (Windows 10 or 11, 64-bit)

The first 3 sessions are free. You'll also need a free Groq API key from console.groq.com.

Windows may show "Windows protected your PC" because the installer isn't code-signed yet: click **More info**, then **Run anyway**.

This repository only hosts the installer downloads. Support: cyclopsapp.ai@gmail.com
